# Conta da Festa

Calculadora simples para estimar quantos salgados e doces comprar para uma festa,
com base no número de adultos, crianças e porções por pessoa.

## Executar localmente

Não há dependências nem etapa de compilação. Abra o arquivo `index.html` no
navegador ou inicie um servidor estático na pasta do projeto:

```bash
python3 -m http.server 8000
```

Depois, acesse `http://localhost:8000`.

## Publicar no GitHub Pages

1. No GitHub, abra **Settings → Pages**.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Selecione a branch `main`, a pasta `/ (root)` e clique em **Save**.

O site será publicado no endereço informado pelo GitHub Pages.
